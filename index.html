GitHub Pages 모바일 웹 배포 방법

이 파일(index.html)은 별도의 백엔드 서버 설치 없이 GitHub Pages에 업로드하는 것만으로 스마트폰 브라우저에서 최대 8명이 방 코드로 함께 접속할 수 있도록 설계되었습니다.

  1. GitHub에서 새 저장소(Repository)를 생성합니다.
  2. 이 코드를 index.html 파일로 저장해 업로드(Commit)합니다.
  3. 저장소의 Settings → Pages 메뉴에서 Branch를 main으로 선택하고 Save를 누릅니다.
  4. 생성된 https://아이디.github.io/저장소명/ 주소를 카카오톡 등으로 친구들에게 공유하면 모바일에서 즉시 방 개설 및 입장이 가능합니다!

✨ 네트워크 기술: WebRTC(PeerJS 공개 브로커) 및 로컬 탭 동기화가 내장되어 있어, 정적 GitHub Pages 환경에서도 실시간으로 8인 방 코드 매칭이 작동합니다.
